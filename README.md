# SQL Lab

Course work for Database Management – SQL & PL/SQL.

## Session 1 – bus pass system
Files in this folder.

Questions:
1. Install MySQL Community Server and Workbench, and take a screenshot
   showing the SCHEMAS list.
2. Draw an ER diagram in Draw.io with passengers, passes and routes
   tables, 3 sample rows in each.
3. Compare MySQL, PostgreSQL, Oracle and SQLite, and pick one for the
   bus pass system.
4. Create bus_pass_db and a passengers table using only the Workbench
   GUI, and add 5 rows.
